# Projeto - Cotação diária de contratos futuros

- Esse é um projeto que consiste em scripts Python para fazer a extração, tratamento e armazenamento de dados que contém a cotação de quatro contratos futuros: açúcar, câmbio, brent e etanol hidratado

✅ 1. Cotação diária dos contratos futuros de açúcar VHP NY11 (Em USD e Reais)

✅ 2. Cotação diária dos contratos futuros de câmbio BRL/USD

✅ 3. Cotação diária dos contratos futuros de Brent

✅ 4. Cotação diária dos contratos futuros de Etanol Hidratado
